## Tool Selection Rules

| Never use X for Y                | Use instead     |
| -------------------------------- | --------------- |
| context7 for web search          | exa             |
| gh_grep for READMEs              | exa or webfetch |
| context7 for code examples       | gh_grep         |
| websearch for GitHub code        | gh_grep         |

## AFT (Code Tools)

AFT tools are available via MCP for code operations (search, navigation, refactoring, safety). Use them over native tools when available. See tool definitions for parameters and usage.
